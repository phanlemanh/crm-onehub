# pre-push-t1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `.githooks/pre-push` bỏ `test` và `build` khi mọi tệp của lần đẩy là tệp T1, và `verify-gate-shape` chỉ nhận nhánh đó qua khối khai `t1Only`.

**Architecture:** Một bộ phân loại mới (`scripts/pre-push-t1.mjs`) gọi lại `quyetDinh`/`tepT1`/`docGlobT1` của CI, đọc danh sách bỏ từ `gate-shape.json`. Hook gom dòng stdin, hỏi bộ phân loại, bỏ tác vụ bằng một dòng `case` đầu thân vòng, chuyển `--bo-qua` cho `verify-gate-shape`.

**Tech Stack:** bash, node ESM (`.mjs`), bun test (`packages/ui`), git.

**Spec:** `docs/superpowers/specs/2026-10-16-pre-push-t1-design.md` · hợp đồng `_acceptance/pre-push-t1/contract.md` · `_acceptance/pre-push-t1/evals.yaml`.

## Global Constraints

- Không chú thích trong code (AGENTS.md).
- Dòng `for task in check-types lint lint:slop test build; do`, dòng `	echo "pre-push: bun run $task" | tee -a "$LOG"` và dòng `	bun run "$task" 2>&1 | tee -a "$LOG" || fail "$task"` giữ nguyên từng byte.
- Dòng bỏ, nguyên văn: `pre-push: chỉ tệp T1 (<n> tệp) — bỏ <ds>; CI phân loại PR theo cùng luật.` với `<ds>` = `t1Only.skip` ghép `, `.
- Dòng lỗi: `pre-push: không phân loại được lần đẩy (<lý do>) — chạy đủ năm bước.`; tệp phân loại vắng: lý do `thiếu scripts/pre-push-t1.mjs`.
- Bộ phân loại luôn thoát 0; lỗi → stdout rỗng.
- Không glob T1 nào, không chữ `"test"`/`"build"` làm danh sách bỏ trong bộ phân loại hay hook.
- `lint:slop` (oxlint) quét cả `.mjs` trong `_acceptance/` và `scripts/`: không `typeof` lúc chạy, không ép kiểu `as unknown`.
- Spec thường trực không gọi git ngoài kho tạm của chính nó (chạy được trong clone `--depth 1`).

## Review Focus
