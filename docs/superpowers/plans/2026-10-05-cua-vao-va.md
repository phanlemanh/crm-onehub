# Cửa vào vá (R1f `cua-vao-va`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** API không đọc được phiên thì trả 503 thay 401 và app hiện trang lỗi tiếng Việt có «Thử lại»; trang Quên mật khẩu giữ logo; đăng xuất lỗi chỉ báo tiếng Việt; trả nợ thước `cua-vao-dang-nhap`.

**Architecture:** Ngữ cảnh tRPC ghi cờ `sessionError` khi `auth.api.getSession` ném; `AuthMiddleware` (và các lớp con phạm vi) cùng `SignedInMiddleware` đọc cờ và ném `SERVICE_UNAVAILABLE`. Proxy của app vốn chỉ coi 401 là hết phiên nên không sửa. Hai `error.tsx` (cấp `[slug]` và `(app)`) dùng chung một thân `TrangLoiTam` dựng bằng `Empty` + `Button`. Khối tiêu đề cửa vào `DauCuaVao` tách khỏi `AuthHeading` để biểu mẫu client dùng được.

**Tech Stack:** NestJS + nestjs-trpc (tRPC 11), better-auth, Next.js 16.3 App Router (`error.tsx` nhận `{ error, retry }`), `@crm/ui`, bun test (+ jsdom preload cho `.dom.tsx`), supertest, puppeteer qua `mot-luot.sh`.

**Spec:** `docs/superpowers/specs/2026-10-05-cua-vao-va-design.md` · hợp đồng `_acceptance/cua-vao-va/contract.md` · evals `_acceptance/cua-vao-va/evals.yaml`

```ts
import { auth } from "@crm/auth";
import { Injectable, Logger } from "@nestjs/common";
import { fromNodeHeaders } from "better-auth/node";
import type { Request } from "express";
import type { ContextOptions, TRPCContext } from "nestjs-trpc";
import type { BaseTrpcContext } from "./context.types";

const logger = new Logger("TrpcContext");

async function docPhien(
	req: Request,
): Promise<Pick<BaseTrpcContext, "session" | "sessionError">> {
	try {
		const session = await auth.api.getSession({
			headers: fromNodeHeaders(req.headers),
		});
		return { session, sessionError: false };
	} catch (error) {
		logger.error(
			{ message: "Could not read the session" },
			error instanceof Error ? error.stack : String(error),
		);
		return { session: null, sessionError: true };
	}
}

export async function createBaseTrpcContext(
	req: Request | undefined,
): Promise<BaseTrpcContext> {
	if (!req) return { req, session: null, sessionError: false };
	return { req, ...(await docPhien(req)) };
}
```

```tsx
"use client";

import { Button } from "@crm/ui/components/button";
import {
	Empty,
	EmptyContent,
	EmptyDescription,
	EmptyHeader,
	EmptyTitle,
} from "@crm/ui/components/empty";
import { useLocale } from "@crm/ui/components/locale-provider";
import { Spinner } from "@crm/ui/components/spinner";
import { useState } from "react";
import { trangLoiMessages } from "@/lib/messages/trang-loi";

export function TrangLoiTam({ retry }: { retry: () => void }) {
	const m = trangLoiMessages(useLocale());
	const [dangThu, setDangThu] = useState(false);

	return (
		<Empty aria-live="polite">
			<EmptyHeader>
				<EmptyTitle aria-level={1} role="heading">
					{m.tieuDe}
				</EmptyTitle>
				<EmptyDescription>{m.than}</EmptyDescription>
			</EmptyHeader>
			<EmptyContent>
				<Button
					autoFocus
					disabled={dangThu}
					onClick={() => {
						setDangThu(true);
						retry();
						setDangThu(false);
					}}
					type="button"
				>
					{dangThu ? <Spinner data-icon="inline-start" /> : null}
					{dangThu ? m.dangThu : m.thuLai}
				</Button>
			</EmptyContent>
		</Empty>
	);
}
```

```tsx
}
```
