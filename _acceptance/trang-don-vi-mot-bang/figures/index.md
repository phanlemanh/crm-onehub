## Đề bài hình

**hoi-1-can-ban** — loại: so hai nhánh (cây quyết định 2 lá). Gốc: «Mục tiêu nào lên ô lọc Cần bàn?». Nhánh A (máy
khuyên): «có ≥1 KR chậm nhịp hoặc trượt» → «tính trên dữ liệu trang đang có · không đổi API · khớp chữ "N KR chậm"
dưới tên mục tiêu». Nhánh B: «thêm KR tự tin thấp (như bản mẫu)» → «phải thêm mức tự tin từng KR vào okr.danhSach ·
đổi API + bài kiểm máy chủ · ~+1 giờ máy». AC liên quan: AC-5.

**hoi-3-nam-ho-so** — loại: so hai nhánh. Gốc: «5 hồ sơ đã ký đo trên trang đơn vị cũ (dat-okr-trong-crm,
khung-okr-truoc-r1, muc-tieu-va-kr, okr-to-chuc-va, toan-canh-okr)». Nhánh A (máy khuyên): «sửa phép đo trong PR
DH2 → ghim lại 5 hồ sơ một lượt (40–80′ máy) → muc-tieu-va-kr AC-3 có dòng Notes trỏ DH2 AC-3». Nhánh B: «hoãn →
5 hồ sơ đỏ ở chiến dịch ghim lại kế → sửa riêng sau; trong khoảng đó không hồ sơ nào chứng trang đơn vị». AC liên
quan: AC-14.
